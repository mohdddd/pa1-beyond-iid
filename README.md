# PA1 — Beyond IID: Inductive Biases, Domain Adaptation, Domain Generalization, Open-Set Recognition

EE-5102 / CS-6304 Advanced Topics in Machine Learning, Fall 2026.

## Repository layout
```
common/    shared utilities (seeding, paths, metrics, checkpointing, logging, plotting)
shared/    PACS protocol + splits shared by Tasks 2 and 3
task1/     inductive biases (ResNet-50, ViT-B/16, CLIP ViT-B-32)
task2/     unsupervised domain adaptation on PACS (target: Sketch)
task3/     domain generalization on PACS (Sketch unseen)
task4/     open-set recognition (CIFAR-10 known, CIFAR-100 unknowns)
report/    figures/ and tables/ generated by the scripts
```
Each task folder has `configs/`, `results/` (machine-readable JSON/CSV) and `NOTES.md`.

## Environment
- Google Colab, NVIDIA T4 GPU. Exact package versions: `environment_freeze.txt`.
- `pip install -r requirements.txt`
- Large artefacts are stored outside git under `$PA1_STORAGE` (datasets, checkpoints, feature caches).

```bash
export PA1_STORAGE=/content/drive/MyDrive/PA1_storage
python -m common.env_check
```
