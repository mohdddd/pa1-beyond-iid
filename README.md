# PA1 — Beyond IID: Inductive Biases, Domain Adaptation, Domain Generalization, Open-Set Recognition

EE-5102 / CS-6304 Advanced Topics in Machine Learning, Fall 2026.

## Repository layout
```
common/    shared utilities (seeding, paths, metrics, checkpointing, logging, plotting)
shared/    PACS protocol + splits shared by Tasks 2 and 3
task1/     inductive biases (ResNet-50, ViT-B/16, CLIP ViT-B-32)
task2/     unsupervised domain adaptation on PACS (target: Sketch)
task3/     domain generalization on PACS (Sketch unseen)
task4/     open-set recognition (CIFAR-10 known, CIFAR-100 unknowns)
report/    figures/ and tables/ generated by the scripts
```
Each task folder has `configs/`, `results/` (machine-readable JSON/CSV) and a `README.md` with details.

## Environment
- Tasks 1–3: Google Colab, NVIDIA T4 (`environment_freeze.txt`). Task 4: Kaggle, 2× T4
  (`task4/results/environment_kaggle.txt`).
- `pip install -r requirements.txt`
- Large artefacts stay outside git: `$PA1_STORAGE` (checkpoints, feature caches) and `$PA1_FAST_DATA`
  (local dataset copies). Commands run from the repository root.

```bash
export PA1_STORAGE=/path/to/PA1_storage PA1_FAST_DATA=/path/to/fast_data
python -m common.env_check
```

## Reproducing each task
Full details (stages, outputs, leakage guards) are in each task's `README.md`.

### Task 1 — inductive biases (STL-10)
```bash
python -m task1.scripts.run_task1 --stage all   # cue-conflict review is a manual step (see task1/README.md)
```
### Task 2 — unsupervised domain adaptation (PACS → Sketch)
```bash
python -m shared.pacs_protocol prepare
python -m task2.train --config task2/configs/source_only.yaml
python -m task2.train --config task2/configs/dan.yaml
python -m task2.train --config task2/configs/dann.yaml
python -m task2.train --config task2/configs/cdan.yaml
python -m task2.train --config task2/configs/dan.yaml --set method.lambda_mmd=0.1 --run-name dan_lmmd0p1
python -m task2.train --config task2/configs/dan.yaml --set method.lambda_mmd=10  --run-name dan_lmmd10
python -m task2.evaluate_final --confirm-final
```
### Task 3 — domain generalization (Sketch unseen)
```bash
python -m task3.train --config task3/configs/erm.yaml      # verifies the reused Task 2 source-only checkpoint
python -m task3.train --config task3/configs/dan_dg.yaml
python -m task3.train --config task3/configs/sam.yaml
python -m task3.train --config task3/configs/dan_dg.yaml --set method.lambda_dg=0.1 --run-name dan_dg_l0p1
python -m task3.train --config task3/configs/dan_dg.yaml --set method.lambda_dg=10  --run-name dan_dg_l10
python -m task3.source_diagnostics
python -m task3.evaluate_sketch --confirm-final
```
### Task 4 — open-set recognition (CIFAR-10 known, CIFAR-100 unknowns)
```bash
python -m task4.data.cifar10
python -m task4.train --config task4/configs/vanilla.yaml
python -m task4.train --config task4/configs/gcsc.yaml
python -m task4.train --config task4/configs/proser.yaml
python -m task4.train --config task4/configs/proser_cleanbn.yaml
python -m task4.evaluation.bn_diagnostic
python -m task4.extract_outputs --stage lock --proser-main proser_cleanbn
python -m task4.extract_outputs --stage extract
python -m task4.evaluate_osr
```
